# OD2 preregistration

## 1. Primary question

On hard diagnostic cases where evidence must be acquired under a budget, does
EDF v0.3 change diagnostic outcomes relative to (a) no framework, (b) an
established method, and (c) a combination of established methods? If so, which
EDF components carry the effect? Is any effect one of accuracy, of efficiency,
or of persuasiveness only?

## 1a. Held-out set

26 cases were authored (two per class). All 26 went through the blind-solve and
adjudication review. Twelve were revised once and three twice. **Two cases were
excluded** under amendment 1, rule 7, because the adjudicator still ruled keys
ambiguous after two revision rounds: OD2-HO-CHANGE-2 and OD2-HO-INCOMPLETE-1. They
are kept in `benchmark/excluded/`. Classes CHANGE and INCOMPLETE therefore have
one held-out case each. **N = 24 cases.** Hashes: `benchmark/frozen-heldout.sha256`.
The plan is 1,080 runs (`experiments/plans/heldout.json`).

## 2. Executors

- Analyzer (primary): `claude-sonnet-5-5`, headless Claude Code 2.1.326, effort
  `medium` unless a condition varies effort. Isolated per run: empty working
  directory, Read tool only, fixed minimal system prompt, no settings or MCP,
  structured output.
- Analyzer (tier replication): `claude-haiku-5-5`, effort `low`.
- Case authors and reviewers: `claude-opus-5-5`, effort `high`.
- Track B rater: `claude-opus-5-5`, effort `low`.
- **Declared limitation.** Every executor is a Claude-family model. Separate sessions
  are not independent models, and Claude ratings are not independent human judgments.

## 4. Primary outcome and analysis

Primary outcome: the OD2 case score (0–100; specification §5, budget from the case).
Unit: the held-out case, with trials averaged within case. Contrasts are paired by
case. Uncertainty comes from seeded paired bootstrap (seed 20261117, 10,000 resamples)
95% intervals. Accuracy (`acc`) and acquisition (`acq`) are reported alongside every
score contrast.

Decision rules. Δ is the paired mean difference; CI is its 95% interval.
- **Material advantage**: Δ ≥ +5 and CI lower bound > 0.
- **Practically equivalent**: CI entirely within [−3, +3].
- **Material disadvantage**: Δ ≤ −5 and CI upper bound < 0.
- Anything else is **inconclusive**. An inconclusive result is never reported as support.

## 5. Hypotheses

| ID | Hypothesis | Test |
|---|---|---|
| H1 | EDF beats no framework | B − A (score) |
| H2 | EDF differs from an established method | B − C |
| H3 | EDF differs from a combination of established methods | B − D |
| H4 | Decision gates and the VOI collection rule improve EDF | F − B |
| H5a–f | Each v0.3 component contributes | B − E_x for each x. **Component necessary**: B − E_x is a material advantage. **Component removable**: practically equivalent. |
| H6 | Sequence matters | B − E_NOSEQ |
| H7a | Compute beats structure at matched or higher cost | A_VOTE5 − B; also reported per USD |
| H7b | EDF is an efficiency gain | Score-versus-cost curves for A and B over effort {low, medium, high, max}. "Efficiency gain" if B at some effort matches A at a higher effort (within 1 point) at ≥ 25% lower mean cost. "Capability gain" if B@max − A@max is a material advantage. |
| H8 | EDF raises persuasiveness more than accuracy | Track B (§7) |
| H9a | Claude-selected methods beat the best fixed method | SEL_CLAUDE − C_KT. C_KT is fixed *ex ante* as the comparator because it was the better of A and C on both dev pilots (84.2 vs 83.4; 86.3 vs 86.0). |
| H9b | EDF as orchestrator beats EDF as fixed procedure | SEL_EDFO − B |
| H10 | Multistep methods add noise | Item test–retest agreement, B vs A (trials 1–2); also C and D vs A. Prediction: B < A. |
| H11 | Effects replicate at a smaller tier | H1, H2 and H4 on Haiku-low |

Multiplicity. H1–H4 are primary. All other hypotheses are secondary and reported
without correction, labelled as such. No result is promoted to a claim of EDF
superiority unless H1 shows a material advantage at both tiers.

## 5a. Ceiling contingency (stated before held-out data)

Dev pilots ran at item-accuracy ceiling. If held-out mean accuracy for A_GENERAL at
Sonnet-medium is ≥ 0.85, results are interpreted through the equivalence rule. A
practically equivalent result (CI within ±3) is reported as "no material
difference detectable on this benchmark for this analyzer". It is never reported
as "EDF has no effect in general".

## 6. Secondary outcomes

Per condition: items read, budget breaches, discriminating-read recall,
unsupported certainty, causal overclaim, missed and false abstention, harmful
and premature promotion, high-confidence error, Brier score, class and domain
breakdowns, tokens (input, cache, output, thinking), cost, wall time, and
invalid runs.

## 7. Track B: accuracy vs persuasiveness

Every valid brief from A, B, C, D, F and SEL arms (Sonnet-medium, trials 1–2) is
rated blind by `harness/Rate.fsx` (persuasiveness 1–7, perceived correctness
0–100, actionability 1–7). Analyses:
1. Paired case-level differences in each rating, B − A and B − C.
2. **Persuasion gap**: perceived correctness / 100 − true weighted accuracy, per
   run. H8 is supported if B − A on the gap is positive with CI > 0 while B − A on
   accuracy is not a material advantage.
3. Discrimination: Spearman correlation between perceived correctness and true
   accuracy, per condition, with bootstrap CI. A method whose briefs persuade
   regardless of correctness lowers this correlation.

## 8. Track C: selection errors

For SEL_CLAUDE, the reported `methodChoice` is coded into {A, B, C, D, combination}.
A **selection error** is a run whose chosen fixed method scored below the best fixed
arm on that case by ≥ 5 points (from the fixed-arm case means). Selection errors are
reported separately from execution errors (runs that chose the best arm and still
scored ≥ 5 below it).

## 9. Integrity

- Held-out cases enter only after review (amendment 1, rule 7). Exclusions are reported.
- Held-out case and truth files are hash-frozen before any held-out run. Truth files
  are never inside any analyzer's working directory.
- Run order is shuffled (seed 20261117). Catalogue labels are shuffled per run.
- Every transcript is preserved. Tool calls are audited: any Read outside the run's
  task and evidence files, or any other tool, is a protocol violation. Violating runs
  stay in the primary analysis as scored. A sensitivity analysis excludes them.
- Invalid outputs score 0 and are never repaired.
- Any deviation is recorded in an amendment with its timing relative to the results.
