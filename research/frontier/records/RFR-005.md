# Minimum Complementary Analytical Lens Set

## Research opportunity

Measure unique lens contribution and find the smallest set that preserves diagnostic completeness and calibration gain.

## Trace

Origins: `docs/framework-engineering/analytical-lens-evaluation.md`, RQ-002 and evaluation metrics; `validation-protocol.md`, default lenses; evidence ledger, unquantified overlap. Assumption: all five current lenses add enough distinct value to justify their cost.

## Methodology

REP: `REP-EDF-LENS-SET-001`. After RFR-001 yields independent analyses, perform leave-one-lens-out and coalition analysis. Score unique accepted observations, control points, blind spots, calibration improvement, redundancy, and time.

## Success

Select a parsimonious default set with predefined non-inferiority margins; retain optional lenses by case type when evidence supports them.

Recommended agent: methodology lead. Effort: 6–8 weeks after RFR-001. Expected knowledge gain: high.
