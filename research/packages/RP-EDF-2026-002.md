# Executive Summary

This review found a framework whose internal self-critique was stronger than its current outward claims.

EDF remains viable as a working diagnostic representation [TH-EDF-001]. Repository-authored cases demonstrate that its fields can organize varied narratives [HY-EDF-001; EV-EDF-001], and one ablation gives suggestive support to separating Origin Network from Propagation [HY-EDF-007; EV-EDF-002].

The repository does not establish independent reproducibility [HY-EDF-005; EV-EDF-004; EV-EDF-005], causal benefit from System Context [HY-EDF-002; EV-EDF-006], better control-point quality [HY-EDF-004; EV-EDF-006], evidence-sensitive updating [HY-EDF-006; EV-EDF-005], or incremental value beyond matched generic structure [HY-EDF-008; EV-EDF-006].

The principal upgrade is therefore epistemic, not cosmetic: current claims are now machine-readable, public claims are checked against them, future confirmatory experiments require raw execution bundles and matched controls, and historical artifacts remain intact without being allowed to overrule later contradictory evidence.

The repository was also simplified to one deployed website implementation and given a zero-dependency integrity suite.

# Current Understanding

## TH-EDF-001 — Working

EDF is a coherent explicit diagnostic grammar. Its current strongest demonstrated value is representational: it forces a diagnosis to expose scope, observations, candidate origins, propagation, evidence, intervention points, uncertainty, and sufficiency.

This is not yet evidence that EDF improves diagnostic correctness or action quality over a credible matched structured alternative.

## TH-EDF-002 — Unestablished

EDF-specific incremental value remains the critical unresolved theory.

A matched neutral structure could plausibly create much of the observed benefit simply by forcing explicit fields and sufficient output length. Until that alternative is controlled, "EDF works" is too broad a conclusion.

## TH-EDF-003 — Working

Execution provenance is part of research validity for framework-performance claims. Summary artifacts alone cannot distinguish an actual replicated effect from shared prompting, evaluator affinity, selective retries, or narrative compression.

# Key Discoveries

## KD-001 — Reproducibility was a construct mismatch

The historical R1 label measured internal structural similarity, not independent reproducibility [HY-EDF-003; HY-EDF-005; EV-EDF-004].

The proof failed not because similarity was absent, but because the measured construct was narrower than the claim.

## KD-002 — Later contradiction had not propagated to current claims

The July 2026 adversarial synthesis already identified eight material contradictions [EV-EDF-006]. The Evidence Ledger, reproducibility summary, and website had not fully inherited that update.

This was a knowledge-propagation defect.

## KD-003 — FCR completeness was overestimated

A frozen FCR can freeze declared configuration, but without exact prompts, model/evaluator versions, raw outputs, errors, failed runs, and scoring code it cannot reconstruct execution [EV-EDF-004; TH-EDF-003].

## KD-004 — The evidence-evolution model used the wrong changing variable

Historical longitudinal work usually changes what is known, not what happened.

The Constitution now correctly models:

`Available evidence changes -> New Evidence Package -> New FCR -> New Validation Run`.

## KD-005 — Structure is the strongest alternative explanation

Many attractive EDF results could be caused by generic structured prompting. This is not a minor nuisance variable; it is the principal competing theory [HY-EDF-008; TH-EDF-002].

## KD-006 — Some framework principles were rhetorical absolutes

Single-root-cause and decision-quality language exceeded the evidence. They were revised into bounded design heuristics.

## KD-007 — Repository complexity exceeded deployed complexity

The production website was static HTML/CSS, while an unused application framework stack remained in the repo. Removing it reduced dependency, build, and drift surface without changing the deployed product.

# Failed Assumptions

1. **Different case IDs imply independent evidence.** False. Shared generation/evaluation creates dependence.
2. **Different named lenses imply independent analysts.** False when one execution system produces them.
3. **Exact percentages imply quantitative rigor.** False without denominator, scoring code, raw outputs, and uncertainty.
4. **A frozen FCR makes an experiment reproducible.** False. It freezes declared configuration, not execution provenance.
5. **Planned evidence isolation demonstrates evidence-sensitive updating.** False. Architecture is not measured performance.
6. **Method capability matrices demonstrate comparative performance.** False. They establish conceptual scope differences only.
7. **Complex outcomes should always have multiple origins.** False as a universal rule. EDF should resist both premature simplification and invented complexity.
8. **Better understanding guarantees better decisions.** False. Decision quality also depends on objectives, execution, uncertainty, values, and changing conditions.
9. **Evidence quality can be represented by one universal ordinal ladder.** False. Evidence quality is claim-relative and multidimensional.
10. **More framework structure necessarily adds semantic value.** Unproven; matched generic structure is the most important control.
11. **"Reproducibility" has one universal operational meaning.** False. Major scientific authorities use different conventions; EDF now qualifies the construct and states the conditions.

## New Principle Candidates

- **Construct-Matched Claiming:** a result can advance only the construct actually measured.

- **Structure Control:** framework-specific value claims require a matched generic-structure baseline.

## Deprecated Principles

- universal ordinal evidence hierarchy;
- implicit equivalence of structural agreement and reproducibility;
- FCR-as-complete-experiment-record;
- universal multi-cause framing.

## Confidence Changes

Positive performance confidence was reduced. Confidence in the narrower conclusion, "EDF is coherent but comparative value remains unproven," increased.

## Predictions Created

- If EDF-specific semantics matter, EDF should beat matched neutral structure on semantic/evidence measures across at least two model families.
- If observed benefit is primarily generic structure, matched neutral structure should be non-inferior.
- If System Context adds only formatting, it should improve structural agreement but not semantic scope correctness.

# Appendix

## A. Current proof boundary

**Demonstrated internally:** the EDF grammar can consistently structure repository-authored diagnoses.

**Suggestive:** some EDF-specific distinctions may improve how reasoning is expressed.

**Not demonstrated:** independent reproducibility, superiority, calibrated confidence, proportional evidence updating, or intervention utility.

## B. Why this does not reject EDF

A matched-structure control is a stronger challenge than simply asking whether EDF examples look useful.

If EDF wins, confidence in framework-specific value increases.

If matched structure ties EDF, the useful result is still actionable: preserve the benefits of explicit structured diagnosis while simplifying or revising EDF-specific theory.

Either result advances understanding.
