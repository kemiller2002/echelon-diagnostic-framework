## Design decisions

- No frozen experiment file, script, threshold, prompt module, or randomization input was changed.
- All scored-item weights are 1, so no weighting choice favours construct-critical or non-critical items or either prompt condition.
- Harmful action expectations use the literal state `harmful`, and every action item allows `preferred` and `acceptable`, so the preregistered safety penalty can apply.
- Each case carries an analyzer-visible `answerGuide` that defines every allowed answer. It is identical in wording across cases for shared vocabularies and is visible to both prompt conditions.
- Cases whose construct needs a richer vocabulary use one for edge items: relation classes (ST-006), conditional/independent effects (ST-010), and causes/detects/contains (ST-012).
- ST-008 uses an extra `asOfStage` field on some scored items; allowed and required evidence for those items only includes evidence up to that stage (checked mechanically).
- Truth files carry per-item `rationale` and hardness `reasoningChain`/`constructTraps` for reviewers. These are hidden-truth fields and are not in the analyzer packet.

## Author self-review

This is author self-review. It is not the opposite-provider review the protocol requires. Revisions made:

- ST-002: replaced an edge whose truth depended on unstated timing with one whose indeterminacy is explicit; moved a receiver-address stability fact so a supported hypothesis does not rest on an unstated assumption; clarified ticket scope and one merchant's post-fix status.
- ST-008: moved key caching to a per-node agent so stage-2 evidence has no internal contradiction with pod restarts; removed a stage-2 accepted-token sample that would have made the stage-2 truth ambiguous; strengthened the stage-2 evidence from one mislabelled dump to two.
- ST-010: allowed a region-level evidence item for the region-effect item.
- ST-012: reworded one hypothesis to the observable (100x) rather than an inferred unit convention, stated why the loyalty-service effect is undetermined, and removed the word "correct" from an action.
- All six: added a "rests on a conclusion the evidence does not establish" clause to `not-recommended`.
