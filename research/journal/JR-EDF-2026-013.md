# Research Journal

## Objective

Resolve the first open item in amendment A002 (JR-EDF-2026-012). `scripts/edf-002-freeze.mjs` did not put `research/experiments/EX-EDF-2026-A003/amendments/` into the freeze manifest, so A001 and A002 could not be frozen, even though A001's `freezeRule` requires it. The experiment owner authorized the change. ROS work item: WI-0013.

## Change

- **New `manifestFiles()` function, exported.** It returns the critical files, then every `*.json` in `amendments/`, then the case/truth files, then the review files. Each directory is listed in sorted order, and a missing directory contributes nothing. `expected()` now takes its file list from `manifestFiles()`. For critical, case/truth and review files the result is the same as before; the only addition is the amendment files.
- **`criticalFiles()` is now exported.**
- **The CLI runs only when the script is executed directly.** This uses the same `import.meta.url` check as `scripts/edf-002-validate.mjs`, so tests can import the module without starting the CLI. `freeze`, `verify` and the usage exit codes are unchanged.
- **New test, `tests/edf-002-freeze.test.mjs`.** It asserts that the manifest includes A001 and A002 and every critical file, and that it has no duplicate paths.

What the freeze covers is otherwise unchanged. The freeze preconditions (`validateCases(true)` and the opposite-provider review check) are also unchanged.

## Validation

- `node --test` (the CI invocation) → 8 tests, 8 pass, 0 fail, including the new freeze-manifest test.
- `node scripts/validate-repository.mjs` → exit 0.
- `node scripts/edf-benchmark.mjs validate` → exit 0.
- `node scripts/edf-002-freeze.mjs verify` → `No frozen-files.json`, exit 1. This is the same behaviour as before, since nothing is frozen.
- `node scripts/edf-002-freeze.mjs bogus` → usage message, exit 2, as before.

## Integrity statements

- The experiment was NOT frozen. `freeze` was not invoked, and no `frozen-files.json` exists.
- No case, truth, review, preregistration, prompt-module, scoring-spec, scoring-code, amendment or output-contract file was modified.
- No analyzer was executed or its output inspected.
