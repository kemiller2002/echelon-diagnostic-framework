## Resolution

1. **OpenAI case and truth files (12 files): r2 lineage taken.** The r2 versions are the ones that now hold passing opposite-provider reviews. The PR #9 versions on the base were superseded, and their reviews do not apply to the r2 files.
2. **Review files (6 files): r2 lineage taken.** After the merge, `git diff eec7de6 -- research/experiments/EX-EDF-2026-A003/cases research/experiments/EX-EDF-2026-A003/reviews` shows only the base's Anthropic-authored cases, which are absent on `eec7de6`. Every OpenAI case, truth and review file is byte-identical to `eec7de6`.
3. **Anthropic-authored cases, amendment A001, scoring-spec v1.0.1, `scripts/edf-002-score.mjs` and its test: base taken.** These had no conflict. The preregistration, prompt modules, randomization, output contract, case and review schemas and authoring contract are identical on both sides.
4. **ROS ledger: renumbering.** The two lineages each allocated WI-0001 onward for different work. The base's WI-0001…WI-0006 keep their IDs. The incoming items were renumbered:

   | Incoming ID | New ID | Work |
   | --- | --- | --- |

   The renumbering was applied to `queue.json`, `queue.md`, `context/current.json`, the `workItem` field of the eight incoming events, and the `workItemId` fields of the four incoming telemetry execution records. ## Open items this integration does not resolve

- **Anthropic-authored cases have no reviews.** ST-002, 004, 006, 008, 010 and 012 still need independent OpenAI opposite-provider reviews (#12 blocker 2). `node scripts/edf-002-review.mjs validate` reports `missing review file` for each.
- **Amendment A001 has a stale ST-003 entry.** Its `ST-003-review-remediation` change retitles the PR #9 ST-003 ("Notification ingress backlog …"). That case version is no longer on this branch, and the r2 ST-003 ("Search 5xx incident during scheduled maintenance") is a different case. The amendment's `unchanged` list also says no case/truth content changed other than that title, which does not hold now that the OpenAI half has been replaced. The amendment was not edited here. Before freeze, its owner should confirm that its scoring changes still hold for the r2 OpenAI cases and should retire or annotate the ST-003 entry.
- **The r2 cases were reviewed under scoring-spec v1.0.0.** Amendment A001 widens precision membership to required ∪ allowed evidence. In every r2 case, required evidence is already a subset of allowed evidence (see the JR-EDF-2026-010 structural audit), so the precision change has no effect on these cases. The harmful-action vocabulary change is additive.
- **Earlier journal entries are missing from this branch.** JR-EDF-2026-005 and JR-EDF-2026-006 (on `main` via PR #14) and JR-EDF-2026-008 (on `experiment/edf-a003-anthropic-rereview-openai-r1`, PR #15) are not here. Only the two r1 review files (ST-001, ST-007) were carried over from JR-EDF-2026-008.
