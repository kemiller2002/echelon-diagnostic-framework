## Harness audit findings and corrections

The analyzer writes terminal run metadata and outputs beneath:

research/experiments/EX-EDF-2026-A003/manual-runs/<slot>/runs

The pre-audit scorer only read:

research/experiments/EX-EDF-2026-A003/runs

Therefore valid completed manual analyzer runs would never become visible to the scorer. This was corrected before freeze. The scorer now discovers both legacy runs and slot-scoped manual-runs directories.

Additional pre-freeze hardening:

- terminal invalid outputs are reported explicitly as not-evaluable; no numeric fallback was invented because the preregistration defines them as terminal but does not preregister a fallback score;
- required evidence is treated as valid evidence by the scorer even defensively;
- validation now requires requiredEvidence to be included in allowedEvidence;
- validation detects duplicate truth item IDs and invalid red-herring/conflict/harmful-action references;
- the freeze manifest now hashes the analyzer harness and freeze script in addition to scoring and validation code;
- regression tests cover manual-run discovery and required-evidence scoring.
