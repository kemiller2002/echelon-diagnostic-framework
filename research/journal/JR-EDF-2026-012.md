# Research Journal

## Objective

Reconcile pre-freeze amendment A001 with the case set that has been on `experiment/edf-a003-pre-freeze-integration` since the JR-EDF-2026-011 integration (merge `ef7785876b0c0f02c0324b4af24504226145dc1d`). ROS work item: WI-0012.

## Findings

- A001 entry `ST-003-review-remediation` retitles the PR #9 lineage ST-003. That case version is no longer in the experiment, so the entry has no target. The current ST-003 is a different case, and it has a passing fresh Anthropic review (JR-EDF-2026-010).
- A001's `unchanged` list says that no case or truth content changed apart from the ST-003 title. That stopped being true when the OpenAI half was replaced by the r2 lineage.
- A001's two scoring changes still hold, and they have no effect on the current 12 cases:
  - In every truth file, required evidence is a subset of allowed evidence, so the union rule leaves precision membership unchanged.
  - Every entry in `harmfulActionCandidateIds` is a scored action whose expected state is `harmful`, so the two harmful-action identification rules agree.
  - Every action vocabulary uses only `preferred` and `acceptable` as promotion answers.
- `scripts/edf-002-freeze.mjs` `criticalFiles()` does not include the `amendments/` directory. A001's own freeze rule therefore cannot be satisfied by the current freeze tooling. This was read from the source only; the script was not invoked.

## Action

A001 was kept unchanged as the historical record. A new record-only amendment, `amendments/EX-EDF-2026-A003-A002-a001-reconciliation.json`, does the following:

- voids A001's ST-003 entry;
- replaces A001's `unchanged` claim about case content, and lists the blob hashes of the current OpenAI case and truth files;
- reconfirms both A001 scoring changes, with the checks above;
- records the freeze-manifest gap and the missing reviews of the Anthropic-authored cases as open items.

A002 changes no scoring behaviour. `scoring-spec.json` still names A001 as its amendment, because v1.0.1's content is unchanged.

## Not done, and why

- **OpenAI opposite-provider reviews of ST-002, ST-004, ST-006, ST-008, ST-010 and ST-012.** These cases are Anthropic-authored, and the review contract requires a reviewer from the other provider family. The contract is `review-schema.json` `passRule`, enforced by `edf-002-review.mjs` and by `reviewErrors()` in the freeze script. An Anthropic-family reviewer cannot produce these reviews, so they must come from an OpenAI-family run.
- **Freeze-manifest gap.** Adding `amendments/` to `criticalFiles()` would change what the freeze covers. That is a change to the experiment's integrity tooling, so it is left for the experiment owner to decide.

## Validation

See the commit for command results. `./ros validate`, `node scripts/edf-002-validate.mjs validate` and the EDF-002 tests were run after the change.

- No case, truth or review file, preregistration, prompt module, scoring spec, scoring code, threshold, randomization or output contract was modified. A001 was not modified.
- No analyzer was executed or its output inspected. The experiment was not frozen, and the freeze script was read but not invoked.
