# EDF v0.3 Frozen Reconstruction

This directory preserves the byte-for-byte EDF v0.3 supporting artifacts from repository commit `f5c8e5cde6e372a616c866ed80a555cee866738e`.

Root EDF documents may contain later interpretation guidance. This directory exists so historical validation can be reconstructed against the material present at the frozen baseline.

`manifest.json` records each original path and Git blob SHA. CI recomputes each snapshot's Git blob hash and fails on drift.

Do not edit files in this directory. Corrections belong in current guidance, a new framework version, or a new research artifact.
