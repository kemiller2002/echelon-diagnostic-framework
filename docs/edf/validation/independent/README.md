# Independent Validation Studies

Status: Working draft

Independent validation studies test whether EDF can be used by analysts who did not create it.

These studies are intended to evaluate reproducibility, clarity, and cross-disciplinary usability.

Agreement is evaluated structurally rather than linguistically. Independent analysts are expected to use different wording while still producing comparable diagnostic structures.
