# Diagnostic Agreement Report (DAR)

## Purpose

The DAR compares IDARs and evaluates reproducibility, agreement, divergence, and framework improvement opportunities.

## Sections

- Study ID
- Evidence Package
- Framework Version
- Number of IDARs
- Analyst Background Summary
- Agreement Summary
  - System Context Agreement
  - Manifestation Agreement
  - Origin Network Agreement
  - Propagation Agreement
  - Control Point Agreement
  - Calibration Agreement
- Areas of Strong Agreement
- Areas of Meaningful Divergence
- Possible Causes of Divergence
  - Domain expertise
  - Framework ambiguity
  - Evidence ambiguity
  - Analyst error
  - Legitimate interpretive diversity
- Participant / IDA Feedback Themes
- Framework Improvement Opportunities
- Recommended Deferred Insights
- Recommended ECRs
- Overall Reproducibility Assessment
