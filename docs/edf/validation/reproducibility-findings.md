# Reproducibility Findings

Status: Working draft

RC-7 is now Reproducibility, not Repeatability.

Reproducibility means independent practitioners using the same FCR should produce materially consistent analyses in structure, principal origins, and high-leverage control points.

Identical conclusions are not required.

Legitimate analytical diversity should be preserved.
