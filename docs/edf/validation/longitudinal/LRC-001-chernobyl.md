# LRC-001 - Chernobyl

Status: Planned. Not yet analyzed.

## Purpose

Chernobyl is the first Longitudinal Reference Case. It will test whether EDF and Framework Engineering respond appropriately as the available evidence changes over time.

## Core Experimental Design

The same event will be analyzed three times under three frozen Evidence Packages.

## Runs

| Run | FCR | Evidence Package | Evidence State |
|---|---|---|---|
| A | FCR-0100 | EP-013A | Evidence reasonably available in 1986 / INSAG-1 era |
| B | FCR-0101 | EP-013B | INSAG-7 revised understanding |
| C | FCR-0102 | EP-013C | Modern historical understanding |

## Purpose Of The Longitudinal Experiment

- Test Diagnostic Stability.
- Test evidence-sensitive framework behavior.
- Identify which EDF conclusions remain stable as evidence improves.
- Identify which conclusions change when evidence changes.
- Avoid hindsight contamination by keeping each evidence state separate.

## Key Caution

Do not treat later evidence as if it were available during earlier runs.

## Planned Comparison Dimensions

- System Context Stability
- Manifestation Stability
- Origin Network Stability
- Control Point Stability
- Confidence Stability
- Diagnostic Sufficiency Stability
- Interpretation Shift
