# Validation Case 003 - Boeing 737 MAX

Status: Working draft

Framework Version:
EDF v0.3 frozen

## Primary Finding

Boeing exposed a large, interacting origin network rather than a simple chain or timeline.

## Observed Pattern

Networked diagnostic topology.

## Key Observation

The issue was not merely that events unfolded over time. The issue was that multiple origins interacted:

- MCAS design
- Single-sensor dependency
- Pilot training assumptions
- Certification delegation
- Incomplete information flow
- Competitive pressure
- Safety governance
- Post-Lion Air response

## Deferred Insight

EDF may eventually need guidance for interpreting large origin networks.

## Status

Deferred / under investigation.
