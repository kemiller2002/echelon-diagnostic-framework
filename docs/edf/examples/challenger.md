# Challenger

Status: Working draft

This is a concise EDF example, not a full historical analysis.

## EDF Read

| Element | Draft |
|---------|-------|
| System | Space Shuttle launch decision and vehicle operation system |
| System Boundary | Shuttle hardware, engineering assessment, launch decision process, and launch governance for the mission |
| Outcome | Shuttle was lost during launch |
| Manifestations | Vehicle breakup; loss of crew; seal failure under launch conditions |
| Origin Network | Technical: O-ring vulnerability in cold conditions. Organizational: risk normalization. Human: acceptance of launch despite unresolved concerns |
| Propagation | Cold conditions increased seal vulnerability; known warnings were normalized; launch proceeded; seal failure propagated into vehicle loss |
| Evidence | Physical failure evidence; pre-launch concern records; launch decision history |
| Control Points | O-ring design; engineering authority; launch governance |
| Control Point Ranking | 1. Engineering authority. 2. Launch governance. 3. O-ring redesign. Governance ranks highest because it can stop recurrence even when technical risk remains |
| Confidence | High on technical origin and strong on governance significance |
| Diagnostic Sufficiency | Yes for the next responsible action |
| Unknowns | Detailed weighting of each governance signal at the final decision point |
| Next Responsible Action | Strengthen engineering authority and launch decision governance while correcting the technical failure mode |

## Why This Example Matters

Challenger is useful because it shows the gap between nearest technical failure and highest-leverage control.

If the diagnosis stopped at "O-ring failure," the system lesson would be incomplete. EDF separates:

- What failed physically
- What made that failure more likely
- Where future intervention should occur

## Concise Takeaway

The outcome was shuttle loss, but the strongest control point was not merely part redesign. It was authority, escalation, and launch decision governance.
