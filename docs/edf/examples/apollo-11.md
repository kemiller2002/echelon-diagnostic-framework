# Apollo 11

Status: Working draft

This is a success diagnosis. EDF should preserve what works, not just explain failures.

## EDF Read

| Element | Draft |
|---------|-------|
| System | Apollo mission design, execution, and support system |
| System Boundary | Mission planning, spacecraft engineering, testing, flight operations, and recovery activities relevant to Apollo 11 |
| Outcome | Mission landed on the moon and returned safely |
| Manifestations | Lunar landing achieved; crew returned safely; mission objectives completed |
| Origin Network | Technical: engineering excellence. Organizational: testing culture. Human: mission clarity. Systems: strong systems engineering and integration |
| Propagation | Clear mission goals, rigorous testing, and strong systems integration reinforced one another throughout design, preparation, and execution |
| Evidence | Mission performance, testing history, design discipline, and execution records |
| Control Points | Preserve testing discipline; preserve engineering rigor; preserve strong systems integration |
| Control Point Ranking | 1. Testing discipline. 2. Engineering rigor. 3. Systems integration discipline. These rank highest because they sustain success across many future missions |
| Confidence | Medium to high as a high-level model |
| Diagnostic Sufficiency | Yes for preserving the main drivers of success |
| Unknowns | Relative weight of each success contributor under different mission conditions |
| Next Responsible Action | Preserve engineering rigor and testing discipline in future mission design and operations |

## Why This Example Matters

Apollo 11 shows that success also emerges from an origin network. The outcome is not adequately explained by one heroic act or one technical component.

EDF is useful here because it identifies the conditions worth preserving:

- Technical rigor
- Strong systems integration
- Clear mission intent
- Testing discipline

## Concise Takeaway

When a system performs exceptionally well, EDF helps protect the conditions that produced that success.
