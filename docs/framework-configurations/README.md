# Framework Configuration Records

Status: Working draft

Framework Configuration Records are immutable records of the complete configuration used for a Validation Case.

Every Validation Case must reference one frozen FCR.

FCRs support reproducibility, traceability, and configuration integrity.

Changing any versioned component requires a new FCR.

FCRs must also record:

- Research Question Set version
- Evidence Package version
- Validation Case version
- Evidence state description when applicable

Longitudinal Reference Case runs require separate FCRs for each Evidence Package.

Example:

- FCR-0100: Chernobyl EP-013A
- FCR-0101: Chernobyl EP-013B
- FCR-0102: Chernobyl EP-013C
