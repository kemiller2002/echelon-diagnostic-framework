# Framework Engineering

Status: Working draft

Framework Engineering tracks how EDF is evaluated, challenged, and improved without changing the frozen meaning of published EDF versions.

EDF and framework-engineering methods evolve independently.

## Longitudinal Reference Cases

Longitudinal Reference Cases examine the same system under multiple frozen Evidence Packages.

They test whether a framework changes appropriately when evidence changes.

See [longitudinal-reference-cases.md](longitudinal-reference-cases.md).

Key related controls:

- Diagnostic Stability
- Research Question Sets
- Evidence Package versioning

## Working Rules

- Validation methods should improve evidence quality without rewriting the EDF specification.
- Every Validation Case should begin with a frozen Framework Configuration Record.
- Analytical lenses are subject to Concept Burden.
- Analytical lenses are subject to No Sacred Concepts.
- Lens changes require evidence across multiple Validation Cases.
